Introduction

The Model XVCC is a voice over IP (VoIP) audio card that supports the microphone and telephone systems with a library of factory-recorded messages. These messages are configured using the Zeus Programming Tool. In addition, the user may customize messages using the composer tool and store them in a separate library. The XVCC can be installed in Desigo Fire Safety Modular / Cerberus PRO Modular systems. It is fitted into the slot of the CC-5 and CC-2 card cages, with one XVCC card required in each enclosure.

Controls and Indicators

The XVCC contains a cared REST button, and 10 LEDs to indicate the operation of the card which are located along the card’s edge and visible through the front panel. Pushing the RESET reinitializes the XVCC. The definition of each LED should be steady on. The Address switches, TENS and ONES, on the front panel of the XVCC allow it to be set according to its assignment in the system. To set the address turn the pointers on each dial to the numbers for the selected address. For example: if the address was 23. Set the pointer for the TENS dial to “2” and the ONES dial to “3”. Two RJ-45 connectors on the front panel established the Wither nest communication of the XVCC in the system. Any of the connectors can be used for connection to PMI-2, PMI-3 or XINC.

Features

The principal features of the XVCC card include:

  • Stores digitized voice announcements and tones; routes them to audio amplifiers
  • Can store up to 300 prerecorded messages and 60 minutes of customized messages
  • Accepts live page input form the LVM and FMT
  • Connects any selected channel of the eight voice audio channels to the monitor speaker mounted in LVM
  • Can be configured through the PMI using the ZEUS Programming Tool
  • Communicates over Ethernet with the PMI-2, PMI-3 and XINC network card
  • Manages the voice subsystem via the CAN bus
  • Supervises the XVCC microphone and phone channels
  • Indicates operational status via multi-colored LEDs
  • Detects loss of PMI communication within the Voice systems
  • Up to 5 LVM can be connected to the XVCC (only one can be active at a time)
  • Meets performance specifications in the commercial temperature range
  • RoHS compliant

Installation

The following components must be set prior to inserting the XVCC card into the CC-5/CC-2:

Address Switch: Set the two –digit address for the card using the two positions switch on the front panel of the card.

CAUTION

Remove all system power before installation, first the battery then the AC. To power up the system, connect the AC first, then the battery.

WARNING

To avoid damage of the XVCC card of the backplane connectors, DO NOT FORCE THE CARD INTO POSITION.

  1. Plug the XVCC perpendicularly into a slot of the CC-5/CC-2 card cage.
  2. When inserting the XVCC into the backplane connectors of the card cage, position it between the two guides and push it gently until the card snaps into place.
  3. Screw the card into the card cage via the captive screws.

The XVCC can be installed into any CC-5/CC-3 slot and connected to PMI via an Ethernet cable. If connected to the XINC card, do not plug the XVCC adjacent to its left side. Doing so will prevent the XINC card from being inserted or removed from the card cage.

If the booster amplifier EBA-2001 is used, connect its X4 pin 2 to the position 9 of the Terminal Block at the front of the CC-5/CC-2 slot for the XVCC, and pin 3 to the position 10. For more information on the booster amplifier refer to the instructions provided in Siemens Industry, Inc., Building Technologies Division, document number A6V10407858 Booster amplifier mainboard (100 W) Mounting Installation.

CAN Wiring

Single Enclosure

To connect the Internal CAN bus (Figure 4):

  1. Install the CCL cable into P3 of the CC-5/CC-2 in the upper left corner of the enclosure.
  2. Install the other end of the CCL cable into the first CAN module on the inner door.
  3. Install one CAN terminator P/N 140-034723in the last CAN module on the inner door.
  4. Install the 120 Ohm CAN termination resistor P/N 140-820150 into TB1 10 and 11 on the PSC-12.

NOTES:

  1. 15 ohms max. for CAN network.
  2. Ground fault detected on the internal CAN Bus at 8.5K ohms or less.
  3. Power limited to NFPA 70 per NEC 760.
  4. All wiring supervised.

Single and Multiple Remote Enclosures

To connect the External CAN Bus (Figures 5 and 6):

  1. Loosen the screws of the terminal block TB1 positions 10 and 11 on PSC-12.
  2. Insert the twisted pair or twisted shielded pair in positions 10 and 11.
  3. Tighten the screws of the terminal block.
  4. Install one CAN terminator P/N 110-134215 in the last CAN module on the inner door. If no modules are installed on the inner door insert the CAN terminator into P3 of the CC-5/CC-2 where the XVCC is installed.
  5. Install the second CAN terminator in the last CAN module in the remote enclosure.
