Introduction

The Model XINC is a card that supports HNET/XNET and CAN network communication within and between enclosures by tunneling the legacy protocols over an IP bus. The IP network can be wired as Class-B or Class-X. Support of both HNET/XNET requires at least one XINC in each enclosure of the Desigo Fire Safety Modular / Cerberus PRO Modular system. Each XINC (HNET or XNET) occupies one HNET address. There will still be a dedicated XINC for HNET and another for XNET just as is done currently with the previous networking cards.

The CAN network can be isolated within a given enclosure or extended externally. External CAN networks require either an RNI, OCM-16 or SIM-16 in the remote enclosure. The CAN address of the XINC does not need to be set. The CAN interface is available regardless of the HNET/XNET selection. Connection to a management station must still use a NIC-C.

The Operating Temperature Range and Humidity is 0 to 49 °C, and 93% @ 32 °C.

Install in accordance with National Electrical Code, ANSI / NFPA 70, the Standard for Installation and Classification of Burglar and Holdup Alarm Systems, UL 681, and the Standard for Central Station Alarm Services, UL 827, as applicable.

Features

The XINC supervises each network for proper operation and reports detected faults to the FCM2041-U2 (Desigo Fire Safety Modular), and FCM2041-U3 (Cerberus PRO Modular) for annunciation. In addition, the XINC has diagnostic LEDs that indicate which faults have been found.

The XINC isolates short circuit faults to each individual segment of the HNET/XNET network. If a short occurs, only the segment of wire between the two XINCs is affected. In a Class-B system the network will be divided into two sections. Communication in each of the sections will continue. For a Class-X network, the fault will be detected, and the network will continue to operate as a single network. A network monitoring jack is included for collecting network logs, located on the front bezel. The XINC supports the LCM-8/SCM-8/FCM-6/OCM-16/ SIM-16 CAN modules.

Control and Indicators

The front panel of the XINC contains one reset switch, five LEDs, and four Ethernet ports as shown in Figure 1. Ethernet port 1 is designated for the connection to the PMI; Ethernet port 2 is for connection for diagnostic tools. Ethernet ports 3 and 4 can be used to connect an XVCC or an additional XINC card. All Ethernet ports on the XINC are for internal use only. The diagnostic port (port 2) must be used only by a qualifies field technician to gather network logs.

A reset switch is located on the top of the front panel. Pushing the reset switch reinitializes the XINC.

The LEDs follow the reset switch, and their functions are defined in the table below:

LEDs

Function

POWER

“ON” indicates the presence of 24V on Pins 17 and 18 of the XINC’s card cage slot.

CARD FAIL

“ON” indicates the card has suffered a fault and is no longer functioning.

TROUBLE

“ON” indicates a general trouble condition and there should be more information present on the PMI.

NETWORK FAULT

“ON” indicates the presence of a fault condition (Open or Short) on one of the Ring Connections (Media Adapters).

GROUND FAULT

“ON” indicates the presence of a Ground Fault condition on one or both Ring Connections (Media Adapters).

Setting Network Address

The XINC has 3 rotary address switches located on the front bezel. The address for the XINC must be the same as the address selected in the Zeus Programming Tool and set in increasing, sequential order. To set the address turn the pointers on each dial to the numbers for the selected address. For example: if the address was 123, set the pointer for the HUNDREDS dial to "1", the TENS dial to "2", and the ONES dial to "3".

Installing the Media Adapters

The XINC is compatible with four media adapters:

  1. FN2016 (Copper CAT Cable Ethernet)
  2. FN2017 (Multi Mode Fiber Optic)
  3. FN2018 (Single Mode Fiber optic)
  4. LDC (Copper Wire Pair)

The media adapters must first be mounted to the XINC and secured with the screws provided before the XINC is inserted into the card cage. The network medium (copper wire, CAT cable, or Fiber Optic), will be inserted through the top of the card-cage card guides. For more information on the media adapters, refer to the following installation instructions: Installation Instructions Model LDC Document ID A6V12198164; Installation Instructions Model FN2016-U1 Document ID A6V13300924; Installation Instructions Model FN2017-U1, FN2018-U1 Document ID A6V13300927.

Please note which part is labeled "IN" and "OUT" for proper system installation and troubleshooting.

Installation

WARNING

Remove all system power before installation; first the battery then the AC. To power up the system, connect the AC first, then the battery.

The XINC can occupy any slot in the CC-2 or CC-5 card cage (Refer to Figure 3). The main processor for the XINC is mounted on the left side of the card. The XINC requires that no card is present in the slot to the left of the XINC when inserting or extracting it from the card cage. There is protection in place to ensure the XINC cannot be slid into or out of the card slot while another card is populated to the left of the XINC.

If the XINC is in the left-most slot it may be necessary to unscrew the standoff on the back of the XINC, if it touches the terminal block, TB1, on the card cage.

WARNING

It is the recommended not to use the right most slot when the LDC modules are present in the XINC.

  1. Plug the XINC perpendicularly into one slot of the CC-2 or CC-5 card cage via two 96-pin DIN connectors.
  2. Slide the XINC card into the card guides front bezel up (lettering on the front panel is legible) until the card cage connectors contact the motherboard receptacles.
  3. Verify that the card edge connectors align properly with the motherboard receptacles. If it does not align, DO NOT FORCE the card. Place thumbs on the front panel adjacent to the captive screws and gently apply even pressure on the card until the connectors plug firmly into the motherboard receptacles.
  4. Screw the XINC to the card cage via the captive screws. Now replace the card to the left before powering the system.

Removing the XINC in the CC-5/CC-2

WARNING

Removing all the system power before installation; first the battery then AC. To power up the system, connect the AC first, then the battery.

  1. Remove the cabling from the top of the card cage.
  2. Remove the card to the left of the XINC.
  3. Remove the XINC.

Next, select “Report”, press the “More Info” button and select the “Operator Interface” (OI). Press the “Configuration” soft key and “Touch” “Appl Rev” for the Application Version. Wiring

WARNING

Remove all power before installation, first the battery then the AC. To power up the system, connect the AC first, then the battery.

Power: Use the Terminal Block from the bottom of the CC-2/CC-5 slot for the XINC and insert the 24 Volts from the PSC-12 Aux terminal into positions 17(+24V) and 18(-24V).

Connection to the PMI

Use the 6ft Ethernet cable provided to connect Port 1 of the Quad RJ 45 on the front of the XINC to the PMI.

Cable Dressing

Provided with the XINC are 2 Ethernet Cables. The 12-inch cable is used to connect the XINC to other cards in the card cage. The 6-foot cable is used to connect the XINC to the PMI on the inner door. It is recommended to locate the XINC and the PMI in the same row of the CAB enclosure. Connect the XINC and the PMI with the 6-foot Ethernet cable then use the Adhesive Cable Tie to dress the excess cable to keep it out of the way and from being accidentally damaged as the door is opened and closed. The Adhesive Cable Tie should go on the strut of the Inner Door, approximately in line with the Ethernet Jack of the PMI.

HNET XINC with XVCC

All external HNET messages are now tunneled over IP. Use the 1ft Ethernet cable to connect Port 4 of the XINC with Port 1 on the XVCC. Both Ethernet cables are provided with the XINC.

XNET XINC with XVCC

All external XNET messages are now tunneled over IP. If a XINC is already set up to tunnel HNET then a second XINC will be dedicated to tunnel XNET.

Ring Wiring Configurations

The Desigo Fire Safety Modular/Cerberus PRO Modular network can be wired using Ethernet cable, single-mode fiber, multi-mode fiber, wire copper pair, or a combination of the four. All field wiring to the XINC is inserted through the top of the CC-2 or CC-5 card cage slot in which it is installed.

To connect the field wiring:

  1. Remove the terminal blocks at the top of the card cage slot for the XINC.
  2. Plug in the appropriate medium (cable, fiber, or copper) to the ring media-adapters.

NOTES:

  1. Power limited to NFPA 70.
  2. All wires supervised.
  3. For wiring topology and ground fault thresholds of the media adapters, refer to the following installation instructions: Installation Instructions Model LDC Document ID A6V12198164; Installation Instructions Model FN2016-U1 Document ID A6V13300924; Installation Instructions Model FN2017-U1, FN2018-U1 Document ID A6V13300927

A media adapter must be inserted into one or both parts of the XINC in order to be connected to the network.

NOTE: Set addresses for Node 1, Node 2, and so forth, in sequential, increasing order. For example, if Node 1 is set at address 4, Node 2 must be address 5, Node 3 must be address 6, etc.

The diagram above shows all the different network topologies. Take note of which XINCs are supporting HNET and which are supporting XNET.

CAN Connection

The CAN bus is connected internally to the CC-5/CC-2 backplane. Internal CAN, for modules inside the enclosure, is supported via terminal block P3 located on the card cage. External CAN, for modules outside the enclosure, is supported on TB1 of the PSC-12.

To Connect the Internal CAN Bus:

  1. Install the CCL cable into P3 of the CC-5 in the upper left corner of the enclosure.
  2. Install the other end of the CCL cable into the first CAN module on the inner door.
  3. Observe the location of the CAN termination devices. Install one CAN terminator P/N 110-134215 in the last CAN module on the inner door. Install the 120 Ohm CAN termination resistor P/N 140-820150 intoTB1 terminals 10 and 11 on the PSC-12.

NOTES:

  1. For wiring topology and electrical parameter properties, refer to the PSC-12M Installation Instructions Document ID A6V12021370.

 

To Connect the External CAN Bus

  1. Loosen the screws of the terminals 10(+), 11(-) and 12 shield of TB1 on the PSC-12.
  2. Insert the wire into the side if the terminal block and tighten the screw.
  3. Observe the location of the CAN termination devices. Install one CAN terminator P/N 110-134215 in the last CAN module on the inner door. If no CAN modules are installed on the Inner door insert the CAN terminator into P3 of the CC-5 where the XINC is installed.
  4. Install the second CAN terminator in the last CAN module in the remote enclosure.

NOTES:

  1. 18 AWG min. 12 AWG max.
  2. Use twisted pair of twisted shielded pair.
  3. Power limited to NFPA 70 per NEC 760.
  4. All field wiring supervised.

NOTES:

The screw terminals can accommodate one 12-18 AWG or two 16-18 AWG.

  1. 18 AWG min. 12 AWG max.
  2. Use twisted pair or twisted shielded pair.
  3. Power limited to NFPA 70 per NEC 760.
  4. All field wiring supervised.
